# 词频与例句面板

**把爱听写页面已返回的单词统计、词形和原文例句整理到一个阅读面板。** 阅读、听力、答案词次数和出现概率分别展示，缺失信息明确显示「暂无数据」。

![词频、概率和例句面板示意](docs/preview.svg)

JavaScript · Tampermonkey · fetch / XMLHttpRequest · MutationObserver · DOM

## 使用

1. 在用户脚本管理器中新建脚本，粘贴 [word-frequency-examples.user.js](word-frequency-examples.user.js)。
2. 打开爱听写，刷新后使用网站的单词查询功能。
3. 网站返回对应单词的统计数据时，右下方会显示独立面板。

下载后可以打开 [demo/index.html](demo/index.html)，使用合成数据体验界面。没有登录要求，也不访问实际网站。

## 实现与修复

- 同时接收目标接口的 fetch 和 XHR 响应；不额外请求、不记录请求参数或原始响应。
- 原实现通过前面几个文本节点猜测字段，可能将阅读次数写到听力位置。公开版按接口字段建立独立面板，保持数据与标签一一对应。
- 未知次数与非法概率保留为暂无数据；词形数量明确标注为「响应中的例句条目数」。
- 例句使用 `textContent` 渲染，完整展示响应中的文本与出处，避免 HTML 注入。
- 不删除网站的弹窗或修改其滚动锁，防止原脚本误伤页面交互。
- 仅匹配同源的指定接口路径；缓存限制为 100 个词。
- 响应克隆异步解析，不延迟原 fetch 返回；重注入会清理旧实例，卸载恢复自己的网络钩子。
